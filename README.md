## 📖 Tentang Proyek

SatuJarak adalah aplikasi berbasis web yang dirancang untuk memfasilitasi dan mendigitalisasi proses pengajuan kerja sama riset, penelitian, maupun Kuliah Kerja Nyata (KKN) di Desa Jarak. 

Sistem ini menjembatani komunikasi antara pihak pemohon (mahasiswa/akademisi) dengan pihak pemerintah desa, memastikan setiap proposal dan status pengajuan dapat dilacak secara transparan dan efisien melalui satu pintu.

## ✨ Fitur Utama

- **Sistem Autentikasi:** Login dan registrasi terpisah antara pemohon dan administrator.
- **Manajemen Pengajuan:** Pemohon dapat mengirimkan proposal dan melacak status persetujuan secara *real-time*.
- **Dashboard Admin:** Antarmuka khusus bagi perangkat desa untuk memverifikasi, menolak, atau menerima pengajuan masuk.
- **Manajemen Potensi Desa:** Modul untuk menampilkan dan mengelola data potensi yang dimiliki oleh Desa Jarak.
- **Antarmuka Modern:** Dibangun menggunakan desain responsif dengan Tailwind CSS untuk pengalaman pengguna yang optimal.

## 🛠️ Teknologi yang Digunakan

- **Framework Backend:** [Laravel 13](https://laravel.com/)
- **Framework Frontend:** [Tailwind CSS](https://tailwindcss.com/)
- **Bundler:** Vite
- **Database:** MySQL
- **Templating Engine:** Laravel Blade
